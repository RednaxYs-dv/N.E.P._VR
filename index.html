// 02 — THE CASE

WHY RUN THE DRILL?

✔ FIELD-TESTED

School fire drills happen once a year. This one runs every night, at 4× speed.

JUST W.T.F. compresses real first-response doctrine into short, replayable runs — so when heat is involved, your hands already know what to do.

Run it yourself →
A

Panic costs seconds. Reflexes save them.

Timed scenarios force decisions under pressure — the same pressure a real alarm creates, minus the actual flames.

B

A mistake here costs nothing.

Pick the wrong extinguisher, open the wrong door, stand up in smoke. Fail freely, learn the consequence, respawn.

C

Built on real doctrine.

P.A.S.S. handling, fire-class agents, stay-low navigation and evacuation order — pulled straight from standard fire-safety training.

D

It's a game first.

Leaderboards, speedrun timers, and a grading system that roasts you — safety knowledge that actually gets replayed.
